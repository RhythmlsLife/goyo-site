01 · OVERVIEW

감각 과부하는 갑자기 오는 것처럼 보이지만, 그 전에 신호가 있습니다

자폐 스펙트럼 당사자는 소리·빛 자극에 개인차가 크고 민감하게 반응할 수 있습니다. GOYO는 환경 자극과 심박 변화를 본인의 평소값과 함께 관찰해 보호자에게 알리는 연구용 웨어러블 시제품입니다.

사용 흐름 (6단계)

웨어러블은 원시 데이터 측정만 담당하고, 판단은 마스터가, 알림은 보호자 휴대폰과 워치가 맡습니다.

  1. 착용

    0:03

    웨어러블을 몸에 달고 손가락에 맥파 센서를 끼웁니다. 마스터 보드와 보호자 휴대폰은 같은 핫스팟에 연결합니다.

  2. 30초 평소값 측정

    0:08

    조용한 30초 동안 이 사람의 평소 소리·빛·심박과 흔들림 폭(표준편차)을 학습합니다. 앱에서 재측정 가능합니다.

  3. 실시간 측정·전송

    0:13

    웨어러블이 원시 데이터를 ESP-NOW로 마스터에 보내고, 앱은 0.5초마다 마스터의 판정 결과를 조회합니다.

  4. 환경 변화 감지

    0:19

    소리가 평소보다 크게 커지거나 조명이 급변하면 해당 채널이 주의·위험 단계로 전환됩니다.

  5. 보호자 알림

    0:25

    위험이 10초 이어지고 다른 채널도 주의 이상이면 Flutter 앱과 Galaxy Watch에 알림이 울리고 원인이 기록됩니다.

  6. 안정 및 쿨다운

    0:50

    환경이 돌아오면 정상으로 내려오고, 같은 알림은 2분 동안 다시 울리지 않습니다.

소리

상대 dB
측정 방식
0.5초 평균 에너지를 평소 대비 상대 dB로 환산 (평소 = 50 dB 기준) 50 + 20·log10(RMS / 평소 RMS)
단계 판정
정상기준 이내 주의평균+2SD
(+6~15 dB) 위험평균+3SD
(+12~25 dB)

절대 음압(dB SPL)이나 청력 검사 dB HL과 다른 사용자 평소 대비 상대 dB입니다.

빛

lux
측정 방식
조도(lux)와 초당 변화량을 측정하며, 실내 정상 범위(100~500 lux) 밖일 때만 평소 대비 비율을 함께 판정합니다.
단계 판정
정상100~500 lux
실내 정상 주의±150 lux/초
또는 ×1.3 위험±300 lux/초
또는 ×1.6

어두워지는 쪽은 ÷1.3, ÷1.6 적용. 3분간 안정되면 새 장소로 보고 평소값을 이동합니다.

심박

BPM
측정 방식
맥파 신호 크기에 맞춰 움직이는 적응형 기준선으로 박동을 찾고, 최근 박동들의 중앙값을 BPM으로 사용합니다.
단계 판정
정상기준 이내 주의평소 +20% 위험평소 +30%

심박 상승만 감지합니다. 심박이 오히려 떨어지는 반응은 감지하지 않습니다.

오경보 억제 및 알림 발동 규칙

한 채널이 순간적으로 튀어 오경보가 반복되면 기기를 벗게 되므로 4단계 억제 조건을 두었습니다.

  1. 위험 10초 유지

    한 채널이 위험 상태로 10초 유지되어야 합니다. 1.5초 이내 짧은 끊김은 이어진 것으로 처리합니다.

  2. 다른 채널 주의 이상

    두 번째 채널이 함께 주의 이상일 때 발동합니다. 한 채널만 60초 넘게 위험이면 안전장치로 발동합니다.

  3. 앱에 10초 표시

    0.5초마다 조회하는 앱이 놓치지 않도록 알림 상태를 10초 유지하고, 알림 횟수가 늘 때만 기록합니다.

  4. 2분 쿨다운

    같은 알림이 연달아 울리지 않도록 발동 후 2분 동안 동일 알림을 다시 울리지 않습니다.

    첫 동작소리 FFT문헌

    보드가 켜지고, 마이크가 주파수를 잡다

    • XIAO 확장 보드와 인두기 추가 구입
    • ESP32-S3에 Blink 예제를 올려 포트 인식과 정상 구동 확인
    • 브레드보드에서 INMP441을 I2S로 연결해 실시간 주파수 분석(FFT)과 시각화 성공. 7,000Hz 시험음에서 약 7,014~7,015Hz 추출
    • 문헌 조사로 감각 과부하와 관련된 위험 주파수 대역(2~8kHz)을 수집 목표로 정리
    • 이때 계획: 웨어러블에서 위험 대역 에너지만 뽑아 BLE로 마스터(Nucleo-64)에 전송 → 이후 변경 (구상과 결정 보기)
  3. 3차6/1
    웨어러블 보드센서 3종

    XIAO 웨어러블 보드로 옮겨 센서 3종 개별 확인

    • XIAO ESP32-S3 핀헤더 납땜, 업로드·시리얼 출력 확인: DevKit 중심에서 착용형 보드 중심으로 이전
    • 소리: 평소 소음 기준 전처리로 박수 칠 때 신호가 뚜렷하게 오르는 것 확인
    • 빛: VEML7700의 lux 값이 빛 변화에 따라 실시간으로 바뀜
    • 심박: MAX30102의 red·ir 원시값이 손가락 접촉에 따라 변함. 안정적인 BPM은 과제로 남음

    • 시리얼 모니터를 켜야만 통신되던 현상: ESP-NOW 문제가 아니라 USB 시리얼 출력 대기(블로킹)가 원인 → 대기 제거
    • 이후 그 관찰 구간에서 마이크 약 16,016샘플/초, 심박 100샘플/초, 244바이트 패킷 약 143개/초를 손실 없이 전달

    • 신호 세기가 약해 외장 안테나가 필요하다는 것과 Wi-Fi·ESP-NOW 채널 불일치를 발견
    • 앱은 Expo Go와 Flutter 두 방식으로 나란히 개발해 하나가 막혀도 진행되게 함

    판정 v0.5개인 평소값하드웨어 변경

    고정 기준에서 '그 사람의 평소'로

    • 사람마다 평소 심박과 민감도가 달라 고정 기준을 버리고, 개인 심박 기준값과 소리·조도 30초 측정의 평균·표준편차로 기준을 잡음

    실기기 연동알림 기록워치

    휴대폰에 실시간 값이 뜨고, 워치가 울리다

    • Android 실기기에서 소리 47~56 dB, 조도 250~339 lux 실시간 표시. 심박은 47 bpm으로 떴지만 정확도는 미검증
    • 핫스팟에서 자동 탐색이 막힐 때를 위해 IP 직접 입력 유지, /calibrate로 30초 재측정
    • 알림 기록을 휴대폰에 저장: 같은 알림이 0.5초마다 중복 저장되지 않게 알림 횟수가 늘 때만 저장, 최대 200건

    • 회의실 300 lux를 '밝음'으로 잘못 판정 → 100~500 lux는 실내 정상으로, 3분간 안정되면 새 장소로 보고 기준 이동
    • 심박 47 bpm 원인으로 샘플링 지연을 의심해 측정 시각 보정 코드(v0.7.4) 작성. 이때는 업로드 전
